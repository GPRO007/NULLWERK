# Contributing

Keep user-facing text in English. Run the unit tests and public-source check. Describe verification scope precisely and use synthetic fixtures.

Submit only original material or material you have the necessary rights to contribute under the project's license. Describe the provenance of substantial additions. Do not submit proprietary executables, SDK binaries, product-specific patch profiles, protected assets, crash dumps, credentials, personal paths or unreviewed reports.

Do not add license-response emulation or content whose purpose is unauthorized access or unlawful circumvention. A label or disclaimer does not determine a contribution's legal treatment; describe its actual function.

Local profiles must use exact hashes, reversible operations and explicit limitations. JSON profiles are excluded from the public project. Keep import-only edits distinct from code changes. See [legal scope](LEGAL.md).
