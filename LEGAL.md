## Purpose and authorization

NULLWERK inspects Windows PE imports and supports explicit, local changes to Steam integration for authorized software maintenance. The public release has no product-specific patch profiles. Its import editor changes import metadata; its optional local profile engine applies exact-hash byte operations. Those capabilities do not establish that a particular modification is permitted.

## Before making a repository or release public

- Review the actual functionality, documentation and downloadable packages together. A neutral name or revised description does not alter what code does or its legal treatment.
- Obtain a qualified review of the intended use, distribution, relevant contracts, and any applicable rules on software protection measures. Software and other protected components can be treated differently.
- Check whether provider-identification, contact, consumer or other publication duties apply. A contributor pseudonym or GitHub issue tracker is not a substitute for legally required information. Do not publish invented publisher details.
- Check contributor rights, runtime licenses and notices, personal data in Git metadata, old tags, release assets and workflow artifacts. Rewriting visible history does not guarantee erasure from caches, old clones or platform records.

Keeping this repository private limits its audience; it does not resolve the legal questions above. These are publication notes, not additional restrictions on the MIT grant.
