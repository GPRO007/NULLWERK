# Local profiles

This release contains no product-specific patch profiles. Analysis and manual Steam-import editing remain available. Automatic code changes require a locally supplied, exact-version profile that you are authorized to use.

Local JSON profiles are excluded from Git by default. Do not submit profiles derived from proprietary products to this repository. The public-source check rejects JSON files in this directory.

See [the profile format](../docs/PROFILES.md) and [legal scope](../LEGAL.md).
