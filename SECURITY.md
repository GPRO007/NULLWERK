# Security

NULLWERK parses untrusted executable files without running them. Report parser defects, unsafe path handling, output overwrite issues, or installer problems through the repository's private security-reporting feature when available. Do not post exploit inputs containing personal data or proprietary binaries in a public issue.

The app does not upload reports or logs. Installer preview builds are unsigned unless a release explicitly states otherwise. Verify release checksums and review the stated validation scope.
